# Class Guides

Class guides focus on abilities, talents, gear, pets or other class systems, and level-based milestones. Shared topics such as character creation and death recovery stay in the [Horde New Player Guide](/docs/new-player/horde).

## Hunter

Follow [Orc Hunter: Levels 1–60](/docs/classes/hunter/orc-1-60) from the Valley of Trials through the first pet, Beast Mastery, Horde leveling routes, dungeons, and endgame preparation.

## Paladin

Follow [Undead Paladin: Levels 1–60](/docs/classes/paladin/undead-1-60) from Deathknell through the Forsaken Paladin class chain, Horde leveling routes, dungeon roles, and the level-60 handoff.

## Shaman

Follow [Windshaper Skyborne Shaman: Levels 1–60](/docs/classes/shaman/skyborne-1-60) from Zephras Isle through the mainland handoff, totem progression, Horde leveling routes, and level-60 role preparation.
