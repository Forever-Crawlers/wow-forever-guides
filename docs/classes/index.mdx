# Class Guides

Class guides focus on abilities, talents, gear, pets or other class systems, and level-based milestones. Shared topics such as character creation and death recovery stay in the [Horde New Player Guide](/docs/new-player/horde).

## Hunter

Start with [Orc Hunter: Levels 1–20](/docs/classes/hunter/orc-1-20), a complete early path through the Valley of Trials, Durotar, the first pet, early Barrens, and optional dungeons.

## Future class coverage

Warrior, Mage, Rogue, Shaman, Warlock, Priest, Druid, and other available Horde class paths will be added as separate, source-reviewed guides.
