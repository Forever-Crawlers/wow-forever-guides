# Start Here

WoW Forever Guides is a practical library for learning the game one decision at a time. You do not need to read everything. Start with the guide that matches where you are right now.

## New to MMOs entirely?

Read [New to MMOs? Start Here](/docs/new-player/intro-mmo) first — what an MMO is, the core loop, combat, pulling, death, chat, and a literal first-session checklist. Then the [Horde New Player Guide](/docs/new-player/horde) for the shared onboarding: installation, character creation, your first quest, bags, travel, professions, campsites, grouping.

## New to the Horde?

Read the [Horde New Player Guide](/docs/new-player/horde). It covers installation, character creation, your first quest, combat, bags, travel, professions, campsites, grouping, and a first-session checklist.

The guide works for every Horde race and class. It uses Normal ruleset examples and plain language, with no prior MMO experience assumed.

## Looking for a class path?

Choose a complete race-and-class path:

- [Orc Hunter: Levels 1–60](/docs/classes/hunter/orc-1-60) — the complete path from the Valley of Trials through pets, talents, dungeons, and endgame preparation.
- [Troll Warrior: Levels 1–60](/docs/classes/warrior/troll-1-60) — normalized rage, Victory Rush, the stance quest, the Arms highway, Riverglades, and the tank handoff.
- [Undead Paladin: Levels 1–60](/docs/classes/paladin/undead-1-60) — the full Forsaken Paladin journey from Deathknell to endgame preparation.
- [Windshaper Skyborne Shaman: Levels 1–60](/docs/classes/shaman/skyborne-1-60) — Zephras Isle, the mainland handoff, totem progression, and the complete journey to 60.

Other race and class guides will follow. Planned sections describe what they will cover instead of linking to empty pages.

## How to use this library

- Read the shared onboarding once.
- Follow the guide for your character while you play.
- Use dungeon, profession, endgame, and reference sections when you reach those systems.
- Check each completed guide's review date and sources when verifying game changes.
