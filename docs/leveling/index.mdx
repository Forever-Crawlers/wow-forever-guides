# Leveling

The systems on this page apply to every class. Class guides (Hunter, Warrior, Paladin, Shaman) turn these into specific routes.

## How Leveling Works in Forever

- Level cap is **60**, permanently. Progression at cap is horizontal — Legacy system, gear, professions, reputation — not a higher level.
- The XP curve is tuned so the 1–60 run is the main journey, not a formality. Expect roughly 8–12 days of played time for a first character.
- Forever adds new zones and over 1,000 new quests alongside the classic world. Classic-era zone bands below still apply; new zones slot in beside them.
- Rested XP accumulates when logged off in an inn or a Leatherworking **camp tent**, and tents let rested XP persist in the field. Log out in a rest area every session.

## The Hub Loop

Zones in Forever are built from quest hubs. The loop is always the same:

1. Arrive at a hub. Take **every** quest offered.
2. Open the map and mark where each objective sits.
3. Clear objectives in one circuit — never cross the same ground twice.
4. Turn everything in at once.
5. Follow any breadcrumb to the next hub.

A hub finished in one circuit beats a hub finished in three trips. The travel between quests is where leveling time actually goes.

## Circuit Grinding

Kill quests are tasks, not detours. The stacking technique:

1. Collect every kill quest a hub offers.
2. Add a "taskkill" while traveling between camps — one mob type that counts for a quest in the direction already moving.
3. Turn in as one loop.

Every kill counts double or triple. This is the single largest speed habit in the game, and it works from level 1 to 60.

## Speed Rules

1. **Stack quests.** Kill quests collected as a bundle, turned in as a loop.
2. **Respect level bands.** Quests three levels above take twice the time for the same XP. A quest two levels below pays half. Stay in the band — see the table below.
3. **Travel is the tax.** Every new flight point taken saves future minutes. Bind the hearthstone at the busiest hub of the current bracket. Run through flight paths once, fly forever after.
4. **Death is sometimes travel.** Graveyards sit closer to quest hubs than characters do. A deliberate death can beat a five-minute run back — calculate it.
5. **Train on schedule.** Class trainers every even level (every level for Warriors). Profession trainers every five skill points missed.
6. **Keep supplies full.** Food, water, ammunition, reagents. A trip back to town for arrows is a quest loop lost.
7. **Campfire buffs.** Well Fed food grants +5% kill XP — the strongest leveling consumable. Camp every logout; keep the buff up.
8. **Dungeons are gear, not XP.** One clean run with quests beats three grinding runs. See [Dungeons](/docs/dungeons).

## The Mount Milestones

- **Level 40:** riding mount, roughly 100 gold including training. The default deadline for every economic habit.
- **Level 60:** epic mount, roughly 1,000 gold. Optional, but it transforms farming.

Fund them with: sell everything grey, auction every unusable green, keep gathering professions current, and never buy gear the auction house sells when a dungeon drops it free.
